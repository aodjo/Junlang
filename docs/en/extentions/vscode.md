# VSCode

The VSCode extension for Junlang provides syntax highlighting for `.junl` files.
You can find the source code in the [`extentions/vscode`](https://github.com/aodjo/junlang/tree/main/extentions/vscode) folder of the repository.

## Installation

Install `Junlang Highlighter` from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=aodjo.junlang-highlighter).
