# VSCode

Junlang 을 위한 VSCode 확장은 `.junl` 파일에 대한 문법 강조(syntax highlighting)를 제공합니다.
소스 코드는 저장소의 [`extentions/vscode`](https://github.com/aodjo/junlang/tree/main/extentions/vscode) 폴더에서 확인해 보실 수 있습니다.

## 설치

[Visual Studio 마켓플레이스](https://marketplace.visualstudio.com/items?itemName=aodjo.junlang-highlighter) 에서 `Junlang Highlighter` 를 설치하세요.
